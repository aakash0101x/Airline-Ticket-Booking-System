# ✈️ Airline Ticket Booking System (C++)

A **C++ console-based application** that allows users to book, view, and cancel airline tickets with **real-time seat availability updates** using **Object-Oriented Programming (OOP) and File Handling**.

## 🚀 Features
✅ **User Authentication** – Signup/Login for Admin & Passengers with file-based credential storage.  
✅ **Flight Management (Admin)** – Add, view, and manage flights dynamically.  
✅ **Flight Search** – Search available flights between source and destination.  
✅ **Ticket Booking** – Real-time seat validation to prevent overbooking.  
✅ **Cancellation with Refund** – Users receive **60% fare refund** on ticket cancellation, and the seat becomes available for others.  
✅ **File Handling** – All flight, booking, and user details are stored persistently in text files.  

## 🛠️ Tech Stack
- **Programming Language:** C++  
- **Concepts Used:** Object-Oriented Programming (OOP), File Handling, Inheritance, Polymorphism  
- **Data Storage:** Text files (`flights.txt`, `users.txt`, `bookings.txt`)
